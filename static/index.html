Getting Started

This tool allows you to visualize time series segmentation model predictions.

Configuration Options

  • Phase Type: Choose between voltage or current analysis
  • Phase Number: Select which phase (1-3) to analyze
  • Number of Samples: Set how many samples to process (10-500)
  • Visualization Type: Choose between comparison dashboard or detailed time series view

Understanding the Results

The visualizations show predicted vs actual segmentation boundaries, helping you evaluate model performance.
